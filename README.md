# Blessed prototype

An interactive mobile web demo for a Latter-day Saint family blessing archive. Try recording or importing a blessing, filing it under a family member, searching and annotating the archive, and exploring the simulated adult account handoff and insights.

[Open the prototype](https://devotronix-apps.github.io/Blessed-prototype/)

Use fictional content. Recordings and edits stay in your browser. Transcription, PDF extraction, and account invitations are simulated.
